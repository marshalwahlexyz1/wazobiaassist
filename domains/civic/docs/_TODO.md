# Government services: sources to collect

Files starting with "_" are ignored by the assistant. Put each source in its own
.md or .txt file in this folder. The first line must name the source, e.g.

    Source: NIMC (https://nimc.gov.ng)

Then paste the relevant official text (plain paragraphs). Check every fact, number,
date and USSD code against the official website. The assistant answers ONLY from
these files.

To collect:
- NIMC: how to enrol for NIN, retrieve NIN (official USSD code), NIN slip
- INEC: continuous voter registration and PVC collection
- NIBSS / CBN: how to get a BVN and check it (official USSD code)
- Nigeria Immigration Service: passport application steps
- CAC: business name registration steps
