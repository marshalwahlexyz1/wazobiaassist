3. Every `{{VERIFY}}` marker sits right after a date, amount, email, phone number or web address. Confirm the value exactly against the official page, then delete the marker. If you cannot confirm it, delete the value (and the sentence if needed).
4. Remove any source URL you did not use; keep only pages you opened.
5. Rename the file without the `_draft-` prefix (for example `cbn-bank-complaints-and-fraud-warnings.md`).
